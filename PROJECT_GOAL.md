## 🎯 Primary Project Goals

1. **Craft & Design Award Quality (Light Theme):**
   - Bespoke Curated Studio Light aesthetic (Warm Alabaster `#FAFAFC`, pure white tactile cards, Editorial Cobalt & Indigo gradients, Ruby Hazard alerts, Jade Outlier conviction).
   - Fluid spring-physics micro-interactions on all cards, buttons, and badges.
   - Interactive **0:00–0:30 Retention Hazard Scrubber** with real-time waveform and script line synchronization.
   - Animated **Hook Score radial gauge (0–10)** with dynamic count-up and celebratory score lift.

2. **Core Feature 1: Daily Prescriptive Briefing ("What to Film Tomorrow" - Step 2):**
   - **Category & Theme Intelligence Engine**: Analyzes your live YouTube API topic clusters, niche taxonomy, and audience data to generate fresh, authentic, domain-native video concepts.
   - **Creator Persona Studio Hero Card**: Displays live avatar, verified channel handle, subscriber count, median views, and exact upload mining metrics.
   - **Production Runbook Modal**: 4-step pacing breakdown with 1-tap handoff to Pre-Flight Simulator.

3. **Core Feature 2: Pre-Flight Content Simulator ("Will this work?" - Step 3):**
   - **Dynamic Heuristic Evaluation**: Hook Strength (0–10), Audience Resonance (0–10), and concrete Views Projection anchored to live channel median views.
   - **30-Second Retention Hazard Timeline**: Flags exact drop-off moments using the creator's actual draft sentences.
   - **3 Actionable Prescriptive Fixes with 1-Click Apply**: Dynamically modifies script and lifts score to 9.2+ Top Outlier.

4. **Monetization Engine (RevenueCat Integration):**
   - Entitlement: `creator_pro_access`
   - Offering: `default_creator_offering` (Monthly `$19.99/mo`, Annual `$149.00/yr • Save 38%`)
   - Free Tier: 3 simulations / month.
   - 4th simulation triggers high-converting Pro Paywall Sheet with 7-Day Free Trial CTA.

5. **Channel Graph & Live YouTube Data API v3 Engine (Dio Helper):**
   - **Pure Handle Initialization**: Connects to live YouTube API using only handle (e.g. `@Telusko`, `@srimankotaru`, etc.).
   - **Zero Static Fallbacks**: Real subscriber counts, total videos, median view computation from live video items, and dynamic NLP topic clustering.
